Après chaque session de jeu

Le jeu enregistre un replay de chaque partie, et Claude y lit tout : decks, tours, boutique, bans. Envoie le dossier des replays après chaque session de jeu : on ne sait pas combien de replays le jeu garde.

  1. Ouvre le dossier du jeu. Dans l'Explorateur de fichiers, colle ce chemin dans la barre d'adresse, puis Entrée :
    %USERPROFILE%\AppData\LocalLow\Ticroco\Spam
  2. Compresse le dossier replays. Clic droit dessus, puis Compresser en fichier ZIP (selon la version de Windows : Compresser vers, puis Fichier ZIP).
  3. Dépose le zip sur GitHub. Ouvrir la page d'envoi
    Elle s'ouvre sur la branche pc-perso. Connecte-toi à GitHub si on te le demande, puis glisse le zip dans la page (25 Mo au plus).
  4. Écris ton message à Claude. En bas, dans « Commit changes », la grande case de description (Add an optional extended description) est ton message : ce que tu as joué, ce que tu cherches, tes questions. Claude le lit.
  5. Valide. Laisse coché Commit directly to the pc-perso branch, puis clique sur Commit changes.
  6. Préviens Claude. Sur l'autre PC, dis-lui : « j'ai envoyé un import ». Sa réponse arrivera dans les Nouvelles, et tes parties dans le Journal.
